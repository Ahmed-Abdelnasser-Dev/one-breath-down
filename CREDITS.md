# Credits

<!--
  Parsed at runtime by scripts/menus/credits_screen.gd, so this file is the single
  source of truth for the in-game Credits screen. Mirror it on the itch.io page
  before release.

  FORMAT (the parser is strict about it):
	## Heading            a top-level section
	### Sub-heading       a group inside a section
	- Name | Author | https://link | note
						  an entry. Author, link and note are all optional, but
						  keep the fields in that order. The link is rendered as a
						  clickable highlight and opens in the player's browser.
    plain line            a paragraph of prose

  HTML comment blocks like this one are stripped and never shown in game, so keep
  maintainer notes inside them. Do not write a comment close marker anywhere other
  than at the end of a comment: the parser closes the block at the first one.

  Entries whose note says "credit required" are contractual. Do not remove them.
  Do not use em dashes anywhere in this file; it is player-facing text.
-->
